# Quiz Answers — M2

1. **B**
   
   解释：Tool schema 定义工具的参数、类型和权限要求。这样 Agent 可以验证参数，用户界面可以生成表单，权限系统可以检查授权。A 错误：schema 不是装饰器。C 错误：虽然可以作为文档，但主要用途是运行时验证。D 错误：schema 不涉及加密。

2. **C**
   
   解释：write_file 有副作用（修改文件系统），需要权限控制。search（A）和 calculator（B）是只读操作，get_time（D）也是只读的。

3. **B**
   
   解释：应该返回 ToolResult.fail，不执行工具。这样 Agent 可以知道错误原因并决定下一步。A 错误：使用默认值可能掩盖问题。C 错误：抛出异常会终止整个 Agent，过于激进。D 错误：忽略错误可能导致不可预测的行为。

4. **B**
   
   解释：工具结果应该转换为 Observation，进入下一轮决策。这样 Agent 可以根据结果决定下一步行动。A 错误：直接打印绕过了决策循环。C 错误：存储数据库不是必须的。D 错误：丢弃结果会让工具调用失去意义。

5. **B**
   
   解释：幂等工具多次执行产生相同结果，例如 search 和 calculator。这意味着可以安全重试。A 错误：幂等性与速度无关。C 错误：幂等工具可以有参数。D 错误：幂等工具可以访问外部资源，只要结果是确定的。
