# Quiz Answers — M1

1. **B**
   
   解释：ModelAdapter 封装 provider 差异，提供统一的模型接口。这样 Agent 的其他部分不需要关心具体使用哪个 provider。A 错误：Adapter 抽象了 provider，不是直接调用。C 错误：这不是为了替代特定框架。D 错误：决策逻辑在 Policy 层，不在 ModelAdapter。

2. **D**
   
   解释：`tool` 角色用于传递工具执行结果。`system` 用于设置行为（A），`user` 用于用户输入（B），`assistant` 用于模型响应（C）。

3. **C**
   
   解释：FakeModel 的主要目的是在没有网络或 API key 的情况下进行离线测试。A 不是主要原因。B 是事实但不是目的。D 错误：真实模型支持工具调用。

4. **B**
   
   解释：应该抛出异常，让调用者决定如何处理。A 错误：忽略错误可能导致后续逻辑出错。C 错误：无限重试会浪费资源。D 错误：正则表达式可能无法处理所有情况。

5. **B**
   
   解释：指数退避通过逐渐增加重试间隔，减少重复请求对服务器的压力，避免在服务器过载时雪崩。A 错误：它实际上减慢了重试速度。C 错误：它不影响重试次数。D 错误：它不直接影响 token 消耗。
