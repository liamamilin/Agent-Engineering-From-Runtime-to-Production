# Quiz Answers — M7

1. **C**
   
   解释：Transient state 是单步骤的临时数据，步骤结束后立即丢弃，程序重启后当然会丢失。Session state 在任务结束后可能丢失，但可以通过 checkpoint 保存。Durable memory 是跨运行持久化的。A 和 D 错误。

2. **B**
   
   解释：Checkpoint 的主要用途是支持中断后恢复运行。当程序崩溃或需要暂停时，可以从上次保存的 checkpoint 继续，而不需要从头开始。A 错误：Checkpoint 不会加速运行。C 错误：Checkpoint 需要额外存储。D 错误：Checkpoint 与模型性能无关。

3. **D**
   
   解释：记忆写入需要策略控制，因为不是所有信息都值得记住（B），这可以节省存储空间（A），并加快检索速度（C）。记住太多无用信息会导致记忆爆炸，降低检索效率。所有选项都是正确的原因。

4. **B**
   
   解释：Episodic memory 是事件和经历（如"用户在某天询问了某事"），Semantic memory 是事实和知识（如"Python 是一种编程语言"）。A 说反了。C 错误：它们有明确区别。D 错误：两者都可以是长期的。

5. **B**
   
   解释：Forgetting policy 的主要目的是避免记忆爆炸，保持记忆质量。通过遗忘过时或不重要的记忆，Agent 可以保持记忆库的相关性和可管理性。A 错误：不是删除所有记忆。C 错误：节省存储是副作用，不是主要目的。D 错误：遗忘本身不会加快检索，但减少记忆数量可以间接提高检索效率。
