# M6 Spec — Retrieval, Grounding & Evidence

## Build
Local search/retrieval tool plus `Evidence` and claim-provenance models.

## Must Teach
- retrieval as information acquisition, not memory itself
- keyword vs semantic retrieval
- chunking/indexing
- query transformation
- reranking
- evidence/provenance
- claim-evidence alignment
- grounded answering
- retrieval metrics (recall/precision or task-oriented proxies)
- RAG as one component inside an Agent

## Lab Acceptance
- local corpus fixtures
- retrieved items preserve source identity
- important claims can attach evidence IDs
- unsupported-claim test exists
- retrieval quality is measured on a small golden set
