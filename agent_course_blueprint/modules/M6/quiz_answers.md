# Quiz Answers — M6

1. **B**
   
   解释：检索是从外部获取信息（如搜索文档），记忆是内部状态持久化（如保存对话历史）。A 错误：它们有明确区别。C 错误：说反了。D 错误：检索不仅用于 RAG。

2. **B**
   
   解释：Evidence 的 provenance 追踪用于追踪信息来源，支持溯源和验证。这样用户可以检查答案的依据。A 错误：追踪不会加快检索。C 错误：追踪增加元数据。D 错误：追踪非常重要。

3. **B**
   
   解释：Claim-Evidence Alignment 检查确保答案有证据支持，减少幻觉。这是构建可信赖 Agent 的关键。A 错误：检查不会加快回答。C 错误：检查不增加 token。D 错误：检查增加复杂性但提高可靠性。

4. **B**
   
   解释：RAG 是 Agent 的一个组件，用于获取外部知识。Agent 是更完整的系统，包含任务管理、状态跟踪、决策循环等。A 错误：RAG 不等于 Agent。C 错误：说反了。D 错误：RAG 是 Agent 的重要组件。

5. **B**
   
   解释：Grounding rate 衡量答案中有证据支持的比例。高 grounding rate 意味着答案更可靠。A 错误：不是速度指标。C 错误：不是文档数量。D 错误：不是 token 指标。
