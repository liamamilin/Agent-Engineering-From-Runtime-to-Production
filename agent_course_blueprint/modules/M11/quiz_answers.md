# Quiz Answers — M11

1. **B**
   
   解释：配置管理系统的主要目的是支持多环境配置，方便部署。不同的环境（开发、测试、生产）可能需要不同的配置，如模型名称、API 密钥、最大步数等。配置管理系统可以加载配置文件，并支持环境变量覆盖。A 错误：配置管理不存储用户数据。C 错误：配置管理不加速执行。D 错误：配置管理不减少 token 消耗。

2. **B**
   
   解释：会话管理的作用是跟踪用户交互状态，支持多轮对话。会话可以存储用户的输入、Agent 的输出、中间状态等信息，使得 Agent 可以在多次交互中保持上下文。A 错误：会话管理不存储代码。C 错误：会话管理不管理权限。D 错误：会话管理不监控性能。

3. **B**
   
   解释：Agent 服务的主要功能是提供 API 接口，让外部系统可以调用 Agent。服务可以包装 Agent，提供 REST API 或 gRPC 接口，使得其他系统可以通过 HTTP 请求调用 Agent。A 错误：服务不训练模型。C 错误：服务不存储日志（虽然可以记录日志）。D 错误：服务不管理配置。

4. **B**
   
   解释：CLI 工具的主要用途是提供命令行操作，方便自动化和脚本化。CLI 可以让用户通过命令行运行 Agent、启动服务、查看状态等，便于集成到自动化流程和脚本中。A 错误：CLI 不是图形化界面。C 错误：CLI 不管理数据库。D 错误：CLI 不监控网络。

5. **B**
   
   解释：监控和可观测性的主要目的是收集指标、健康检查，确保系统可靠运行。监控可以收集请求数、错误率、延迟等指标，健康检查可以检查系统是否正常运行。这些信息对于调试、优化和确保系统可靠性至关重要。A 错误：监控不加速执行。C 错误：监控不直接减少成本。D 错误：监控不提高模型性能。
