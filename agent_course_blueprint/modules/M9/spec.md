# M9 Spec — Delegation, Multi-Agent & Protocols

## Build
One composition example using agent-as-tool, handoff, or supervisor/worker; optional version-isolated protocol adapter.

## Must Teach
- composition before multi-agent
- specialization and delegation
- agent-as-tool vs handoff
- supervisor/worker
- planner/executor/reviewer
- shared vs isolated context/state
- communication contracts
- duplicate work / deadlocks / cost explosion
- MCP as capability/context integration
- A2A-style protocols as independent-agent interoperability
- single-agent baseline comparison

## Lab Acceptance
- composed system is evaluated against single-agent baseline
- communication payload is typed/structured
- context leakage boundary is demonstrated
- multi-agent is rejected for at least one case where it adds no value
