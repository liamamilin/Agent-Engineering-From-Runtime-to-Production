# Quiz Answers — M4

1. **B**
   
   解释：评估在添加能力之前进行，是为了建立基线，知道改进是否有效。没有基线，无法判断改进是真实的还是偶然的。A 错误：评估需要时间。C 错误：这不是为了应付要求。D 错误：评估非常重要。

2. **B**
   
   解释：分层评估可以定位具体问题所在。例如，如果任务失败但动作正确，问题可能在输出阶段。A 错误：分层计算更复杂。C 错误：代码更复杂。D 错误：单一分数无法诊断问题。

3. **B**
   
   解释：Golden tasks 提供标准化的评估用例，确保评估的一致性和可重复性。A 错误：Golden tasks 不用于训练。C 错误：虽然可以帮助调试，但不是主要用途。D 错误：Golden tasks 是手工设计的，不是生成的。

4. **C**
   
   解释：如果选择了正确的工具（Action 正确）但输出错误，问题可能在 Context（上下文构建错误）或 Transition（状态更新错误）。A 错误：Action 是正确的。B 错误：Policy 选择了正确的工具。D 错误：Task 规范应该是正确的。

5. **B**
   
   解释：Trace 回放的主要用途是检测回归和调试。通过重放相同的模型输出，可以检查 Agent 行为是否一致。A 错误：回放不会加速。C 错误：回放需要相同的 token。D 错误：回放不用于训练。
