# Quiz Answers — M10

1. **B**
   
   解释：最小权限原则是只授予 Agent 完成任务所需的最小权限。这可以减少安全风险，防止 Agent 访问不必要的资源或执行不必要的操作。A 错误：授予所有权限违反最小权限原则。C 错误：不授予任何权限会导致 Agent 无法工作。D 错误：根据请求授予权限可能导致权限过宽。

2. **B**
   
   解释：Guardrail 的主要作用是验证和过滤输入输出，确保安全。Guardrail 可以防止恶意输入、敏感信息泄露、格式错误等问题。A 错误：Guardrail 不会加速执行，可能会减慢。C 错误：Guardrail 不直接减少 token 消耗。D 错误：Guardrail 不提高模型性能。

3. **B**
   
   解释：预算管理的主要目的是控制资源消耗，防止过度使用。预算管理可以限制 token 消耗、执行时间、成本等，防止 Agent 无限运行或消耗过多资源。A 错误：预算管理不是限制能力，而是控制资源。C 错误：预算管理确实增加复杂性，但这不是目的。D 错误：预算管理不直接减慢执行。

4. **B**
   
   解释：断路器的作用是防止故障级联，提供优雅降级。当某个服务频繁失败时，断路器会打开，阻止后续请求，给服务恢复的时间。这可以防止故障扩散到整个系统。A 错误：断路器不加速恢复，而是给服务时间恢复。C 错误：断路器可能降低吞吐量，但提高稳定性。D 错误：断路器不减少网络延迟。

5. **B**
   
   解释：重试策略中的指数退避是重试间隔随重试次数指数增长。例如，第一次重试等待 1 秒，第二次等待 2 秒，第三次等待 4 秒，等等。这可以给系统更多时间恢复，同时避免重试风暴。A 错误：固定间隔不是指数退避。C 错误：线性增长不是指数退避。D 错误：不进行重试就不是重试策略了。
