# Quiz Answers — M3

1. **B**
   
   解释：正确的顺序是 Observe -> Decide -> Act -> Transition。首先获取观察，然后基于观察做决策，执行动作，最后更新状态。A 顺序错误。C 和 D 顺序完全错误。

2. **B**
   
   解释：State 是结构化的运行时信息，Messages 是为模型交互构建的视图。A 说反了。C 错误：它们不是同义词。D 错误：State 包含更多信息，不只是工具结果。

3. **B**
   
   解释：终止原因用于调试和评估，区分成功、失败和预算耗尽。这对于理解 Agent 行为和诊断问题至关重要。A 和 C 不是主要用途。D 错误：终止原因非常重要。

4. **C**
   
   解释：如果模型返回空响应，应该产生 fail 决策并终止。A 错误：继续循环会浪费资源。B 错误：空响应不是成功。D 错误：无限重试会导致无限循环。

5. **B**
   
   解释：用确定性控制器包裹概率性策略，让 Agent 行为可审计、可调试、可控制。即使模型行为不确定，整个系统的行为也是可预测的。A 错误：这不直接影响速度。C 错误：这不减少 token 使用。D 错误：这实际上增加了代码复杂度，但换来了可控性。
