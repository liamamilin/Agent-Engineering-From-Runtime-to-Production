# Quiz Answers — M8

1. **B**
   
   解释：Reactive loop 每步动态决策（observe-decide-act），而 explicit planning 预先制定计划然后执行。A 错误：速度不是主要区别。C 错误：两者都可以使用模型。D 错误：它们有明确区别。

2. **A**
   
   解释：步骤依赖关系确定执行顺序，确保前置步骤完成后再执行后续步骤。B 错误：依赖关系不会加速执行。C 错误：与 token 使用无关。D 错误：依赖关系很重要。

3. **A**
   
   解释：Workflow 是确定性的状态机，有明确的状态和转换条件；Plan 是步骤列表，支持依赖关系但执行更灵活。B 错误：说反了。C 错误：它们有明确区别。D 错误：复杂度不是区分标准。

4. **B**
   
   解释：人类审批主要用于防止高风险操作（如删除文件、发送邮件）造成不可逆损害。A 错误：减慢速度是副作用，不是目的。C 错误：增加成本不是目的。D 错误：合规要求是原因之一，但不是主要原因。

5. **B**
   
   解释：Replanning 的触发条件包括：步骤失败、意外结果、新信息使原计划失效。A 错误：每步 replan 开销太大。C 错误：达到最大步数应该终止，不是 replan。D 错误：人类请求可以触发，但不是主要触发条件。
