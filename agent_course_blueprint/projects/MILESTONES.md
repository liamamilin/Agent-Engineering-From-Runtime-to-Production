# Milestone Projects — V2

## Milestone 1 — Local Tool Agent (after M3)

A CLI Agent with explicit TaskSpec, State, model-backed/fake Policy, local tools, transition logic, budgets, and termination reason.

## Milestone 2 — Measured Grounded Agent (after M6)

Add traces, evaluation, ContextBuilder, retrieval and Evidence objects. Important factual claims must be grounded in retrieved evidence.

## Milestone 3 — Stateful Planning Agent (after M8)

Add checkpoint/resume, memory policy, explicit planning or deterministic workflow, and at least one human approval gate.

## Milestone 4 — Composed Agent System (after M9)

Add justified specialization using agent-as-tool, handoff, or supervisor/worker. Compare quality, cost, latency, and failure rate against the single-agent baseline.
